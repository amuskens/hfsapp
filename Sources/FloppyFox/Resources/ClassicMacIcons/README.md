# Classic Mac icon artwork

`ClassicMac.png`, `Floppy.png`, and `HappyMac.png` are recreated Classic Mac
icons by Thomas Reed, sourced from
https://github.com/thomasareed/Classic-Mac-icons.

`ClassicDocument.svg` and `ClassicFolder.svg` are compact recreations made for
FloppyFox's generic HFS file and folder fallbacks. The folder uses the familiar
late System 7 blue/lavender appearance. Both use an integer pixel grid so they
remain crisp at the browser's 18-point size.

The upstream repository does not currently include an explicit software or
artwork license. Confirm redistribution permission with the author before
shipping these assets in a public binary.
