# Classic Mac icon artwork

`ClassicMac.png`, `Floppy.png`, and `HappyMac.png` are original artwork generated by
`Tools/generate_classic_mac_icons.swift`, licensed the same as the rest of this repository.

`ClassicDocument.svg` is a compact recreation made for FloppyFox's generic HFS
file fallback. It uses an integer pixel grid so it remains crisp at the
browser's 18-point size. Generic folders use the current macOS system artwork.
